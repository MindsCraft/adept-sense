AdeptSense API Documentation

The AdeptSense API provides identity verification services including NID OCR, face match, liveness verification, name translation, and gender estimation. All endpoints accept JSON and return JSON.

Base URL https://api.adeptsense.tech/v1
Sandbox URL https://api-sandbox.adeptsense.tech/v1
Content Type application/json
Supported Formats JPEG · PNG · WebP

Authentication

All API requests require a Bearer token in the Authorization header:

HTTP Header
Authorization: Bearer YOUR_API_KEY

You can generate API keys from your dashboard. Keep your keys secure — do not commit them to version control or expose them client-side.

Quickstart

Get from zero to your first successful API call in under 5 minutes.

1

Get your API key

Sign up at adeptsense.tech and generate a key from the dashboard.

2

Install the SDK (optional)

npm
npm install @adeptsense/node
3

Make your first call

Node.js
import AdeptSense from '@adeptsense/node'

const client = new AdeptSense({
  apiKey: process.env.ADEPT_KEY
})

const result = await client.verify.nid({
  front: frontBuffer,
  selfie: selfieBuffer,
  liveness: true
})

console.log(result.verified) // true

Sandbox Environment

Safe testing. The sandbox uses mock responses — no real NID data is processed and no credits are consumed.

Use the sandbox base URL for all testing and development:

https://api-sandbox.adeptsense.tech/v1

Sandbox responses return realistic mock data with the same schema as production. Switch to the live URL when you're ready to go live.

POST /verify/nid

Extract structured identity fields from a Bangladesh NID card image. Supports both smart-card and old-format NIDs.

Request Body

ParameterTypeRequiredDescription
front_imagestringYesBase64-encoded front of NID
back_imagestringNoBase64-encoded back of NID
selfiestringNoBase64-encoded selfie for face match
livenessbooleanNoEnable liveness verification
face_matchbooleanNoEnable face match against NID photo

Response — Format A (Current)

200 OK
{
  "verified":         true,
  "liveness_score":   0.97,
  "face_match_score": 0.94,
  "name":             "Md. Rafiqul Islam",
  "name_bn":          "মোঃ রফিকুল ইসলাম",
  "nid_number":       "••••••4821",
  "dob":              "1988-03-12"
}

Response — Format B (Enhanced)

422 Unprocessable
{
  "verified":            false,
  "error_code":          "ERR_IMAGE_BLURRY",
  "error_message":       "OCR couldn't read text",
  "recommended_action": "Ask user to retake photo"
}

POST /verify/face-match

Compare a live selfie against an ID portrait to determine if they belong to the same person.

ParameterTypeRequiredDescription
selfiestringYesBase64-encoded selfie image
referencestringYesBase64-encoded reference/ID photo

POST /verify/liveness

Verify that a submitted image or video is from a live person, not a photo, mask, or digital replay.

ParameterTypeRequiredDescription
imagestringYesBase64-encoded face image or video frame
session_idstringNoSession ID for async webhook result

POST /translate/name

Convert a Bangla name to its English transliteration for cross-system identity matching.

ParameterTypeRequiredDescription
name_bnstringYesName in Bangla script

POST /predict/gender

Predict gender from a given name using name intelligence models trained on South Asian naming conventions.

ParameterTypeRequiredDescription
namestringYesFull name (English or Bangla)

Score Thresholds Guide

Use these thresholds to interpret face_match_score and liveness_score values:

Score RangeVerdictRecommended Action
0.90 – 1.00Strong matchAutomatic approval
0.70 – 0.89Possible matchFlag for manual review
0.00 – 0.69No matchReject

Webhooks

For asynchronous liveness results, AdeptSense can POST a callback to your server when the result is ready.

Webhook Payload
{
  "event":      "verification.completed",
  "session_id": "ses_a1b2c3",
  "result": {
    "verified":       true,
    "liveness_score": 0.97
  },
  "timestamp": "2025-01-15T10:30:00Z",
  "signature": "sha256=abc123..."
}

Verify the signature header using your webhook secret. Retries use exponential backoff (1s, 5s, 30s, 5m).
