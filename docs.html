AdeptSense API Documentation

The AdeptSense API provides identity verification services including NID OCR, face match, liveness verification, name translation, and gender estimation. All endpoints accept JSON and return JSON.

Base URL https://api.adeptsense.tech/api/v1
Sandbox URL https://api-sandbox.adeptsense.tech/api/v1
Content Type application/json
Supported Formats JPEG · PNG · WebP

Authentication

All protected API requests require your custom API key passed in the x-api-key HTTP header:

HTTP Header
x-api-key: YOUR_API_KEY

You can generate API keys from your dashboard. Keep your keys secure — do not commit them to version control or expose them client-side.

Quickstart

Get from zero to your first successful API call in under 5 minutes.

1

Get your API key

Sign up at adeptsense.tech and generate a key from the dashboard.

2

Prepare files & request

Use Node, Python, or standard cURL client to upload images to the API endpoint.

3

Make your first call

Node.js
import fs from 'node:fs/promises'
import FormData from 'form-data'

const form = new FormData()
form.append('front', await fs.readFile('./front.jpg'), 'front.jpg')
form.append('back', await fs.readFile('./back.jpg'), 'back.jpg')

const res = await fetch('https://api.adeptsense.tech/api/v1/ocr/nid', {
  method: 'POST',
  headers: {
    'x-api-key': process.env.ADEPT_KEY
  },
  body: form
})

const result = await res.json()
console.log(result.ok) // true

Sandbox Environment

Safe testing. The sandbox uses mock responses — no real NID data is processed and no credits are consumed.

Use the sandbox base URL for all testing and development:

https://api-sandbox.adeptsense.tech/v1

Sandbox responses return realistic mock data with the same schema as production. Switch to the live URL when you're ready to go live.

Poll this endpoint with taskId to fetch the async face comparison results.

Score Thresholds Guide

Use these thresholds to interpret face_match_score and liveness_score values:

Score RangeVerdictRecommended Action

0.70 – 0.89Possible matchFlag for manual review
0.00 – 0.69No matchReject

Webhooks

For asynchronous liveness results, AdeptSense can POST a callback to your server when the result is ready.

Webhook Payload
{
  "event":      "verification.completed",
  "session_id": "ses_a1b2c3",
  "result": {
    "verified":       true,
    "liveness_score": 0.97
  },
  "timestamp": "2025-01-15T10:30:00Z",
  "signature": "sha256=abc123..."
}

Verify the signature header using your webhook secret. Retries use exponential backoff (1s, 5s, 30s, 5m).

WebView Flow Integration

If you're using our hosted verification UI (/liveness?token=...) inside mobile or web applications, you can receive completion events natively via WebView and JavaScript bridges.

A) Web (iframe + postMessage)

Listen for liveness completion event payload using standard browser message handler:

JavaScript
const livenessUrl = "https://api.adeptsense.tech/liveness?token=YOUR_TOKEN";
document.getElementById("lvFrame").src = livenessUrl;

window.addEventListener("message", async (event) => {
  if (event.origin !== "https://api.adeptsense.tech") return;
  const msg = event.data || {};
  if (msg.type !== "liveness.result") return;

  const sessionId = msg.sessionId;
  // Fetch result securely from your backend -> /api/v1/liveness/result?sessionId=...
  console.log("Session complete:", sessionId);
});

B) Flutter (flutter_inappwebview)

Register Javascript handler name livenessResult in the controller:

Dart
final String livenessUrl = "https://api.adeptsense.tech/liveness?token=YOUR_TOKEN";

InAppWebView(
  initialUrlRequest: URLRequest(url: WebUri(livenessUrl)),
  onWebViewCreated: (controller) {
    controller.addJavaScriptHandler(
      handlerName: "livenessResult",
      callback: (args) async {
        final payload = args.isNotEmpty ? args[0] : null;
        final sessionId = payload?["sessionId"];
        // Call your backend proxy -> /api/v1/liveness/result?sessionId=...
      },
    );
  },
);

C) iOS (Swift + WKWebView)

Observe the userContentController with script handler name livenessResult:

Swift
import WebKit

config.userContentController.add(self, name: "livenessResult")
webView.load(URLRequest(url: URL(string: "https://api.adeptsense.tech/liveness?token=YOUR_TOKEN")!))

func userContentController(_ userContentController: WKUserContentController, didReceive message: WKScriptMessage) {
  guard message.name == "livenessResult" else { return }
  if let payload = message.body as? [String: Any],
     let sessionId = payload["sessionId"] as? String {
       // Call your backend to verify -> /api/v1/liveness/result?sessionId=...
  }
}

D) Android (Java/Kotlin + WebView)

Create a JavaScript interface class bound as AndroidLiveness:

Kotlin
class LivenessBridge {
    @android.webkit.JavascriptInterface
    fun postMessage(payloadJson: String) {
        // Parse JSON -> extract sessionId -> retrieve results via backend
    }
}

webView.settings.javaScriptEnabled = true
webView.addJavascriptInterface(LivenessBridge(), "AndroidLiveness")
webView.loadUrl("https://api.adeptsense.tech/liveness?token=YOUR_TOKEN")
