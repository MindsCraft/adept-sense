Five page-top directions for subpages

The top of a subpage is the first thing a reader sees after the navbar. These five options range from restrained centered to highly structured three-column. Built with the project's actual tokens (deep purple #7C3AED on warm ink) and fonts (Plus Jakarta Sans, Lora, JetBrains Mono). The page top continues straight into the page body below.

P1 centered P2 rail split P3 mono breadcrumb P4 section index P5 editorial rail
P1 Editorial centered default · recommended

↑ Centered. Mono eyebrow → giant serif title → restrained sub → two CTAs. Symmetrical, easy to scan, works on every page type. This is what most premium docs sites ship (Linear / Stripe / Vercel blogs).
