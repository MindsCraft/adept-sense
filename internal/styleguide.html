AdeptSense · Internal Style Guide v0.3 Variant C · Deeper

Black & white, deep purple when it matters.

A mostly-monochrome system with one loud accent (deep purple #4B1D95 — one shade brighter than the logo's #26125B, same hue family), one quiet voice (the logo's deep purple, reserved for code), and red #BB2D2E kept tiny — eyebrow dot, live indicator, danger. Open styleguide.html side-by-side to compare against the all-red Variant A.

Variant A · red-as-accent

  • Red carries brand, chips, links, eyebrows, focus ring
  • ~8% per-screen — heavy for an identity-verification context
  • Risks reading as "danger" on first scan (Stripe/Vercel reserve red for errors)
  • Logo's red blends with UI red — mark loses its pop

Variant C · deep purple + tiny red

  • Purple #4B1D95 — same hue family as logo's deep purple #26125B, one shade brighter
  • Red #BB2D2E appears only at: eyebrow dot, live indicator, destructive CTA
  • Reads as Linear / Plaid / Mercury — premium-fintech, not bright violet Stripe
  • Logo's red and purple now feel like one family with the UI accent
  • All three logo colors present, each at its honest ratio
