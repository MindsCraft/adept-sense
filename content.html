How it works

From document to decision in under a second.

Three clean steps — session, data, response.

1

Start a session

Create a verification session and choose your integration path — web WebView, native Android/iOS SDK, or direct API call.

"session_id": "ses_a1b2c3"
"mode": "webview"
"expires_in": 600
2

Collect identity data

Upload NID front/back images, selfie captures, or name inputs through a secure, encrypted workflow.

"front_image": "base64..."
"selfie": "base64..."
"liveness": true
3

Receive verified JSON

Get a structured response with OCR fields, match confidence score, and liveness result — ready to store or act on.

Secure WebView Flow

Embed a hosted verification journey inside any web or hybrid app — no camera permissions to manage.

import AdeptSense from '@adeptsense/node'

const client = new AdeptSense({
  apiKey: process.env.ADEPT_KEY
})

// Verify NID + liveness + face match
const result = await client.verify.nid({
  front: frontBuffer,
  back: backBuffer,
  selfie: selfieBuffer,
  liveness: true,
  faceMatch: true
})

// { verified: true, score: 0.97, ... }
console.log(result.verified)
