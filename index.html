How it works

From document to decision
in under a second.

Three clean steps — session, data, response.

1

Start a session

Create a verification session and choose your integration path — WebView, native SDK, or direct API call.

"session_id": "ses_a1b2c3"
"mode":       "webview"
"expires_in": 600
2

Collect identity data

Upload NID front/back images, selfie captures, or name inputs through a secure, encrypted workflow.

"front_image": "base64..."
"selfie":      "base64..."
"liveness":    true
3

Receive verified JSON

Get a structured response with OCR fields, match confidence score, and liveness result — ready to act on.

"verified":        true
"liveness_score": 0.97
"name":           "Rafiqul Islam"
